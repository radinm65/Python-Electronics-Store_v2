# Python Electronic Store — V2

A terminal-based electronic store management system developed in Python, simulating real-world retail operations for cameras, smartphones, and laptops. This second version builds upon the original project by introducing **database integration**, using MySQL for relational data and MongoDB for product reviews.

The project emphasizes **Object-Oriented Programming (OOP)**, database design, data persistence, role-based access control, and automated reporting.

## Features

- **Object-Oriented Design:** Structured implementation using OOP principles.
- **Role-Based Access:** Separate roles and permissions for managers and employees.
- **Product Sales:** Manage product sales and process transactions.
- **Relational Database:** Use MySQL to store and manage structured data and relationships between entities.
- **NoSQL Database:** Use MongoDB to store and manage product reviews.
- **Database Integration:** Work with both relational and document-based databases within a single application.
- **Seller Payments:** Handle payments to sellers based on sales.
- **Automated Reporting:** Generate reports identifying top-performing sellers and customers.

## Technologies

- Python
- Object-Oriented Programming (OOP)
- MySQL
- MongoDB
- SQL
- NoSQL

## Project Overview

This project demonstrates how Python can be used to build a database-driven management system with multiple user roles, sales workflows, and automated reporting. By combining MySQL for structured relational data with MongoDB for flexible review documents, the project explores the practical use of different database models within a single command-line application.
